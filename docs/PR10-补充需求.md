## 验证证据与限制

- 本地：AST 只读语法检查、Ruff、git diff --check 通过。没有本地编译、构建、源码测试或冒烟脚本。
- 远端：当前功能提交正在跑既有 Test and build macOS DMG 流程，完成后在此补充真实运行链接与结果。
- Fetch 校验 JWT 结构，不验证签名、过期时间或账号额度；系统凭据库登录但没有 auth.json 的情况明确提示缺文件，不擅自改登录状态或凭据存储设置。[OpenAI 官方说明](https://developers.openai.com/codex/auth/)。
- Configuration 的保存校验不执行在线认证；保存后可在 Connections 刷新确认网络和机器身份权限。HTTP 按需求支持，远端连接应使用 HTTPS。
- 未提交的输入在页面切换与失败时保留；退出设置需使用保存/应用，或明确选择 Discard。不同工作目录之间不迁移配置。
- 未进行本机真实账号 Token 获取或新的真实服务调用验收；不会把旧版本 provider-check 结果冒充本次补充的验收证据。
