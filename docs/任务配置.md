# 配置与迁移

本地 `.env` 只负责 Infisical 启动连接。开发时先参考仓库 `.env`；打包软件固定读取 Settings 中所选工作路径下 `PRBot-workspaces/.env`，未选择则使用应用数据目录的 workspaces。进程里的 INFISICAL_* 参数可覆盖该文件。不会在任意任务目录搜索凭据。

| 来源 | 键 | 说明 |
| --- | --- | --- |
| 本地文件或进程环境 | INFISICAL_URL | 默认 https://app.infisical.com |
| 本地文件或进程环境 | INFISICAL_CLIENT_ID、INFISICAL_CLIENT_SECRET、INFISICAL_PROJECT_ID | 机器身份与项目，必需 |
| 本地文件或进程环境 | INFISICAL_ENVIRONMENT、INFISICAL_SECRET_PATH | 默认 dev、/ |
| Infisical | UPSTASH_REDIS_REST_URL、UPSTASH_REDIS_REST_TOKEN | 对话服务必需，后端使用 |
| Infisical | TELEGRAM_BOT_TOKEN | 仅 Telegram 服务需要；兼容旧键 PR_BOT_TOKEN |
| Infisical | PRBOT_TELEGRAM_ACTOR_ID | Telegram 执行任务的绑定用户；未配置时不接受远端执行 |
| Infisical 或宿主 Git 凭据 | GITHUB_TOKEN | 可选显式来源；账号须有目标仓库权限 |
| Infisical | PRBOT_LOG_LEVEL | 默认 INFO |
| Infisical | PRBOT_POLL_TIMEOUT | 1–10 秒，默认 10，保证健康报告不过期 |
| Infisical | PRBOT_TASK_TIMEOUT | 默认 3600 秒 |
| Infisical | PRBOT_REQUIRED_CHECKS | 默认 test,dmg，按目标仓库实际检查名配置 |
| 本机 Codex 登录 | ~/.codex/auth.json | 完整登录，id_token 在 Connections 明文显示；不再导入钥匙串 |
| 本地非密钥偏好 | PRBOT_WORK_ROOT | 用户选择的工作路径，仅此字段保留在 config.json |

Infisical 使用 Universal Auth 取得短期访问凭据，读取指定项目、环境、路径的 `/api/v4/secrets`，只在进程内缓存一分钟。刷新 Connections 强制重新读取。缺少配置列出键名，网络和认证错误不转发上游响应正文。

旧 Token 输入、保存、Keychain API、允许范围表单、登录自启动命令和持久化注册均已移除。旧 config.json 的这些字段在升级时丢弃；不访问、修改或删除其他应用的钥匙串项目。旧版队列不自动执行。

Redis 原子容量检查、幂等键、游标分页和归档重试见 README。默认保存期限为不过期，达到 10 MB 应用数据预算时拒绝写入；不会因会话输入等待 15 分钟过期而删除历史。

参考：[Infisical Universal Auth](https://infisical.com/docs/api-reference/endpoints/universal-auth/login)、[Secrets List](https://infisical.com/docs/api-reference/endpoints/secrets/list)、[Upstash REST](https://upstash.com/docs/redis/features/restapi)、[Codex App Server](https://learn.chatgpt.com/docs/app-server)。

任务受理时会记住工作目录和配置文件路径。更换工作路径后，原任务及其保存重试仍从原来的 .env 连接 Infisical；缓存按连接参数隔离，不会把上一目录的配置复用到新目录。原配置不可用时保留待保存结果，恢复原配置后重试，不把历史写到其他项目。
